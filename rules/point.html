ゴルフの握り「ポイント制」のルールと計算方法

SQORE編集部 ｜ 2026年11月10日更新

ポイント制とは、バーディ・パー・ボギーなど打数の「役」（その打数の呼び名）ごとに点を決めておき、各ホールで各自がその点を取って、全員との差で精算する握り（＝仲間内でポイントを競う定番ゲーム）です。4人で回って自分だけバーディ10点なら、自分は+30、ほかの3人は−10ずつです。どの役に点を付けるかで、ゲームの荒れ方がまったく変わります。

基本ルール

  1. スタート前に、役ごとの点を決めます（例: イーグル50点・バーディ10点・それ以外0点）。
  2. 各ホールで、自分の打数に当たる役の点を取ります。PAR3のニアピンにも点を付けられます。
  3. そのホールの収支は「自分の点×人数 − 全員の点の合計」。これは相手1人ずつとの点の差を足したものと同じで、全員の収支を足すと必ず0になります。

計算例（4人・パーやダボにも点を付けた場合）

点の設定: バーディ10・パー5・ボギー0・ダボ−5・トリ以上−10・ダブルパー−10・ニアピン10
PAR3で A=バーディ＋ニアピン（20点）、B=パー（5点）、C=ダボ（−5点）、D=ダブルパー（6打、−10点）
全員の点の合計 = 20＋5−5−10 = 10点
A = 20×4−10 = +70 ／ B = 5×4−10 = +10 ／ C = −5×4−10 = −30 ／ D = −10×4−10 = −50（合計0）

SQOREはダブルパーを最初に判定します。そのためPAR3の6打は「トリ以上」ではなく「ダブルパー」の点になります。ホールインワンやアルバトロスは、イーグル以上の点です。

数えてみた：パーとダボに点を付けると、実力差が4.7倍に開く

ポイント制は「どの役に点を付けるか」を自由に決められるのが魅力です。ただ、付け方しだいで勝ち負けの開き方が大きく変わります。10万ラウンドをシミュレーションして、2通りの設定を比べました。

  • A: バーディ以上だけ（SQOREの既定）… イーグル50・バーディ10・ニアピン10、ほかは0
  • B: パーとダボにも付ける … Aに加えてパー+5・ダボ−5・トリ以上−10・ダブルパー−10

80で回る人+72pt+296pt
90で回る人+6pt+82pt
100で回る人−30pt−112pt
110で回る人−48pt−266pt
80と110の差120pt562pt
（4.7倍）

理由は役の出る回数にあります。バーディは80で回る人でも1ラウンドに1.6回ほどですが、パーとダボ以上は毎ラウンド何回も出ます。

パーやダボに点を付けると、この回数の差がそのまま積み上がります。110で回る人が勝ち越す確率は、Aなら7%、Bだと0.1%。ほぼ毎回負けるゲームになってしまいます。

逆に、腕前が近い組ならBも楽しめます。全員90前後の4人だと、1人あたり動くのはAで平均42pt、Bで67pt。誰が勝つかは最後まで分からず、勝ち越す確率はどちらも4割台でした。

目安: 腕前に差がある組はA（バーディ以上だけ）、近い組で動きを大きくしたいならB。差がある組でパーに点を付けたいなら、ホールベストやオリンピックのように、その場の勝負で点が決まるゲームを組み合わせるほうが偏りません。

よくあるローカルルール

  • ニアピン — PAR3のニアピンに点を付けます。誰も乗らなかったら次のPAR3へ持ち越す決め方が定番です。
  • 3パット・OB・ペナルティ・バンカーの減点 — 打数の役とは別に、出来事ごとに減点します。OBとペナルティは1回ごと、バンカーと3パットはホールで1回、という数え方が多いです。
  • ボギーに点を付ける — 初心者が多い組では、ボギーに+点を付けて「ボギーでも取れる」ようにする決め方もあります。

SQOREでの扱い

設定できること

アプリのSQOREの既定はイーグル50・バーディ10・ニアピン10（誰も取らなければ次のPAR3へ持ち越し）で、パー以下の役は0点です。

パーは0点以上、ボギーは加点・減点のどちらも、ダボ・トリ以上・ダブルパーは減点を設定できます。3パット（ホールで1回）・OB（1回ごと）・ペナルティ（1回ごと）・バンカー（ホールで1回）の減点も付けられます。

3パットやOBの減点は、パット数やOBの回数を入力したホールだけで数えます。

よくある質問

ポイント制の握りとは？

ゴルフの握り（＝仲間内でポイントを競う定番ゲーム）の一つで、バーディ・パー・ボギーなど打数の役ごとに点を決めておき、各ホールで各自がその点を取って、全員との差で精算するゲームです。

ポイント制の計算方法は？

各ホールで、役（イーグル・バーディ・パーなど）ごとに決めた点を各自が取ります。そのホールの収支は「自分の点×人数−全員の点の合計」です。4人で自分だけがバーディ10点なら、10×4−10で+30、ほかの3人は−10ずつになります。全員の収支を足すと必ず0です。

パーやボギーにも点を付けるべき？

腕前が近い組なら付けると盛り上がり、差がある組なら付けないほうが無難です。80・90・100・110で回る4人の試算では、バーディ以上だけに点を付けたときの80と110の差は1ラウンド120ptでしたが、パー+5・ダボ−5・トリ以上−10・ダブルパー−10を足すと562ptと4.7倍に開きました。110で回る人が勝ち越す確率も7%から0.1%に下がります。

ホールインワンやアルバトロスは何点？

SQOREではパーより2打以上少なければすべてイーグルの点になります。PAR3のホールインワンも、PAR5の2打（アルバトロス）もイーグル扱いです。別の点にしたい会は、手動ポイントで上乗せしてください。

PAR3の6打はトリプルボギー？ダブルパー？

SQOREではダブルパーを先に判定するので、PAR3の6打はダブルパーの点になります。PAR4の7打はトリプルボギー、8打からダブルパーです。トリ以上とダブルパーに違う点を付けるときは、この順番だけ先に伝えておくと揉めません。

何人からできる？

2人から何人でもできます。人数が増えるほど1つの役で動く点も増え、自分だけが点を取ったときは、4人なら自分の点の3倍、5人なら4倍が自分の収支になります。

ポイント制の握りを計算できるアプリはある？

アプリのSQOREなら、打数を入れるだけで役の判定から全員との精算まで自動です。ゲームのポイント計算と精算は無料で使えます。iPhone・Androidのどちらにもあります。

この記事の検証方法

4人のラウンドを10万回シミュレートして集計しました。1ホールの打数は、平均80・90・100・110のアマチュアの役の出現率（例: 90で回る人はバーディ4%・パー29%・ボギー40%・ダボ19%・トリ以上8%）から各ホール独立に引いています。ニアピンは、PAR3で1打目が乗る確率を腕前ごとに置き（80で40%〜110で8%）、乗った人から1人を選びました。精算はSQOREアプリの実装と同じで、そのホールの収支 = 自分の点×人数 − 全員の点の合計、役はダブルパー→イーグル以上→バーディ→パー→ボギー→ダボ→トリ以上の順に判定しています。3パット・OBなどの減点とハンデは付けていません。
