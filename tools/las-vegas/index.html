ラスベガス計算ツール

無料・インストール不要｜SQORE

ゴルフの握り「ラスベガス」のポイントを、打数を入れるだけで自動計算できる無料ツールです。2桁の数字づくり、バーディ反転、カット、引き分けのキャリー、リーチ、チームのローテーションまで対応。入力はブラウザに自動保存されるので、ラウンド中にそのまま使えます。ルール自体を知りたい方はラスベガスのルールと計算方法をどうぞ。

ルール設定（バーディ・カット・キャリーなど）
HPAR 倍率結果

清算（ポイント）

全ホールゼロサム（全員の合計は常に0）で計算します。リーチは倍率ボタン（×1→×2→×3）で設定でき、引き分けホールのリーチはキャリーに引き継がれます。

使い方

  1. プレイヤー名（表の見出し）を入れます。並び順=打順としてチーム分けに使います。
  2. 各ホールのPARを合わせて、4人の打数を入力します。
  3. 入力した瞬間にホールの勝敗ポイントと清算が自動計算されます。引き分けは次のホールにキャリーされます。

計算例

基本の計算（PAR4・数字の差方式）

チームA: 4打と5打 → 45／チームB: 5打と6打 → 56
差は 56 − 45 = 11。Aチームの2人が+11pt、Bチームの2人が−11ptです。

キャリーが絡む例

1番ホールが同数字で引き分け → 2番ホールは倍率×2。2番ホールで差11なら 11×2=22pt が動きます。さらに引き分けが続けば×3、×4と増えていきます。

バーディ反転の例

Aチームの1人がバーディ → Bチームの数字56が65に反転。A=34なら差は65−34=31ptに跳ね上がります。バーディとダブルパーが重なると反転+倍でさらに大きく動きます。

よくある質問

無料ですか？登録は必要ですか？

無料です。インストールも会員登録も不要で、このページを開くだけで使えます。

ページを閉じたら入力は消えますか？

消えません。この端末のブラウザに自動保存されるので、開き直せば続きから入力できます。「すべてクリア」でリセットできます。

3人でもできますか？

人数で「3人」を選ぶと、4人目にゴースト（ボギー固定またはダボ固定）が自動参加します。ゴーストのポイントは同チームの実プレイヤーに合算されます。ゴーストをルーレット（平均スコアから抽選）にしたい場合はアプリのSQOREをどうぞ。

ローカルルールはどこまで対応していますか？

バーディの反転／倍、両チームバーディの相殺・両方反転、ダブルパーの反転／10の位+1、トリカット・ダブルパーカット、キャリー、リーチ（手動倍率）、チーム分け3方式+ローテーション（1H毎・3H毎）、両者パー倍付に対応しています。ハンデ（.5や1打引き）やニアピン・ドラコンの同時集計はアプリ版で対応しています。
